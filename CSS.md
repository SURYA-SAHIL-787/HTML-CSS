# FINAL MEGA PROJECT — RESPONSIVE EDUCATIONAL INSTITUTION WEBSITE

Take the educational institution website from the HTML roadmap and style it with CSS. Use one shared stylesheet across the site.

### BUILD REQUIREMENTS

- **HOME** — Style the hero, navigation and featured programs. Use Flexbox for the navigation and a responsive Grid for the featured cards.
- **ABOUT** — Set a comfortable reading width and a clear type hierarchy for the timeline and glossary.
- **PROGRAMS** — Build a card grid that adapts from one column on narrow screens to multiple columns when space allows. Keep thumbnails proportional and buttons aligned.
- **SCHEDULE AND FEES** — Style the table captions, headers and cells. Give wide tables a scrollable wrapper on small screens.
- **ADMISSIONS AND CONTACT** — Style labels, fields, buttons and keyboard focus. Stack fields on narrow screens.
- **CAMPUS MEDIA** — Keep images, video and embeds inside their containers. Preserve access to captions and transcripts.
- **STUDENT RESOURCES** — Style the FAQ and resource links so interactive elements are easy to recognize and use.
- Reuse CSS variables for colors and spacing. Add one subtle transition and honor the reduced-motion preference.

### FINAL ACCEPTANCE CHECKLIST

- [ ] All pages use the shared stylesheet and have consistent type, spacing and navigation.
- [ ] At narrow, medium and wide widths, the page fits the viewport and wide tables scroll inside their wrappers.
- [ ] Navigation, form controls and disclosures have visible keyboard focus.
- [ ] Images and embeds fit their containers, and enlarged text stays readable.
- [ ] Text and controls have readable contrast. Essential information is available without motion.
- [ ] The site uses HTML and CSS.
